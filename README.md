# Python-Project-Quantum-Mechanics
A shared repository to ease the workflow during the Python Project on Quantum Mechanics.

When adding new code submissions, add a new code section to contain the code.
This is done to limit the negative inteferrence with the existing code.
When doing this, please also add a note in the log that explains the implementations.

If you're adding unfinished code bits, please note them as unfinished.
This way, other people know not to run that part of the code when testing.
